# llm.txt — contexto para modelos de linguagem

EscovaBits é um visualizador de assembly inspirado no Compiler Explorer.

## O que é

Escreva C++ ou Go no editor web, o servidor compila o código e devolve o assembly gerado, filtrado sem diretivas e labels mortas.
